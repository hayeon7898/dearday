## 📂 File Structure

```
📦 project
├── app/                    # Expo Router 기반 화면 (file based routing)
│   └── (tabs)/             # 하단 tap의 navigation
│       ├── onboarding/     # 온보딩 화면
│       ├── today/          # 오늘의 기록 메인 화면
│       ├── compose/        # 기록 작성 화면
│       ├── day/            # 날짜별 기록 상세 화면
│       └── mypage/         # 마이페이지 / 설정 화면
|
├── component/              # 재사용 UI components
├── assets/                 # 이미지, 폰트 등 정적 리소스
├── utils/                  # 공통 util functions
|
└── supabase/
    └── functions/          # Supabase Edge Functions 
```
